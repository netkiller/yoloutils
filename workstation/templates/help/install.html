环境安装

安装 Python 虚拟环境、PyTorch CUDA 包和 netkiller-yoloutils。

返回帮助

本地环境

工作站通过 SSH 管理远程算力，使用密码连接时需要本机安装 sshpass。

macOS

brew install hudochenkov/sshpass/sshpass

Linux

# Debian / Ubuntu
sudo apt update
sudo apt install -y sshpass

# CentOS / Rocky / AlmaLinux
sudo dnf install -y epel-release
sudo dnf install -y sshpass

Windows

# 建议使用 WSL
wsl --install
wsl
sudo apt update
sudo apt install -y sshpass

首次安装

python3.14 -m venv /srv/python
source /srv/python/bin/activate
python -m pip install --upgrade pip
pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu130
pip install netkiller-yoloutils -i https://pypi.tuna.tsinghua.edu.cn/simple --upgrade

日常升级

pip install -U ultralytics --upgrade
